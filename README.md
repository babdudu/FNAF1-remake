# Five Nights at Freddy's 1 

A JavaScript recreation of Five Nights at Freddy's 1, built using only plain JS/DOM and HTML.

## About This Project

This is a browser-based implementation of FNAF 1, where you play as a night security guard trying to survive from 12 AM to 6 AM while being hunted by animatronics. The game features camera monitoring, door controls, and a power management system.

## Objectives

This project follows the objectives:

### Game Features
- **Timer**: In-game clock counting from 12 AM to 6 AM (game time)
- **Score**: Points based on frightening encounters
- **Lives**: Power bar (0-100%) - when power reaches 0%, game over
- **Pause Menu**:
  - Continue game
  - Restart night

### Controls
Smooth, responsive keyboard input (accessible with mouse too)
  - Camera: `SPACE` (toggle on/off)
  - Left Door: `Q` (close/open)
  - Left Light: `A` (close/open)
  - Right Door: `E` (close/open)
  - Right Light: `D` (close/open)
  - Pause menu: `ESC`
